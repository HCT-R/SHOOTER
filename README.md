# Pixel Protocol 4.0

Трёхмерный шутер с видом сверху в промышленном sci-fi окружении. Сглаженный рендер, 25 видов оружия, шесть сюжетных миссий и три соревновательных режима.

## Запуск

Откройте **index.html** для автономной кампании и тренировок с ботами. Интернет и установка сервера для этого не нужны.

Для комнат с друзьями нужен Node.js 22 или новее:

```powershell
npm ci
npm start
```

Откройте **http://localhost:3000**. Выберите арену, создайте комнату и передайте друзьям её код или ссылку из кнопки «ПРИГЛАСИТЬ». Каждый участник подтверждает готовность; создатель запускает матч. Свободные места заполняют боты. По умолчанию сервер допускает до 32 участников в матче, включая ботов; `ROOM_CAPACITY` задаёт предел развёртывания.

На другом компьютере откройте LAN-адрес машины с сервером или его общий HTTPS-адрес, затем введите код комнаты.

Свой сервер в интернете для дуэли с другом (Docker, HTTPS, `npm run deploy`): [DEPLOY.md](DEPLOY.md).

Настройка Discord Activities: [DISCORD.md](DISCORD.md). Публичная публикация и испытание двух участников внутри настоящего Discord требуют приложения владельца и HTTPS-хостинга.

## Режимы

| Режим | Игровой цикл |
| --- | --- |
| Кампания «Операция Затмение» | Шесть карт, 45 этапов: исследование, записи, сопровождение инженера, оборона, реактор, боссы и эвакуация. Контрольные точки, снабжение, развитие бойца и выбор открытых миссий. |
| Дуэль | До пяти побед; одинаковые комплекты, смена сторон, 90 секунд и 30 секунд сужения зоны. Размен считается ничейным раундом; предел матча — 15 минут. |
| Каждый за себя | 20 устранений или пять минут; при равном счёте учитываются смерти. Возрождение через три секунды, защита 1,5 секунды до первой атаки, выбор снаряжения и вход в текущий бой. |
| Батл-рояль | Пистолет и нож на старте, воспроизводимая добыча, ограниченные патроны, аптечки и пять этапов зоны до восьми минут. Выбывшие и присоединившиеся во время боя наблюдают за живыми. |

Мини-карта доступна только в кампании. В соревновательных режимах она не строится и не рисуется. Сервер передаёт координаты только видимых противников; звуки скрытых источников сообщают приблизительное направление. Прогресс станции не переносится в PvP.

## Оружие и управление

Сохранены десять прежних стволов. Добавлены тяжёлый револьвер, винтовка с отсечкой, DMR, снайперская винтовка, двустволка, автоматический дробовик, ПП с глушителем, ручной пулемёт, гранатомёт и арбалет. Ближнее оружие: нож, мачете, тактический топор, энергокопьё и молот. У моделей отдельные магазины, затворы и другие движущиеся детали; портреты строятся из тех же моделей.

Ящики снабжения показывают содержимое: патроны, гильзы, болты, взрывчатые боеприпасы, энергоблоки или топливо. Медицинские кейсы имеют два размера. Эти же модели представлены на складе крупными превью. У каждого ближнего оружия собственные стойка, обычная и тяжёлая атаки с движением корпуса; звук удара привязан к контакту, сетевые анимации плавно воспроизводятся между снимками сервера.

| Действие | Управление по умолчанию |
| --- | --- |
| Движение / прицел | WASD / мышь; левый / правый стик |
| Выстрел или обычный удар | ЛКМ / правый триггер |
| Прицеливание или тяжёлый удар | ПКМ / левый триггер |
| Перезарядка / рывок | R / пробел |
| Носимые слоты | 1–5 в кампании, 1–4 в FFA/BR; колесо, Q/E, бамперы |
| Взаимодействие / подбор оружия | V / нажатие левого стика (L3) |
| Аптечка в BR | H / нажатие правого стика (R3) |
| Смена участника при наблюдении | Q/E, колесо или бамперы |
| Снабжение на контрольной точке | B |
| Пауза / настройки | Escape |

Кампания: пистолет, три основных оружия и выбранное ближнее. FFA/BR: пистолет, два основных и ближнее. В FFA весь каталог доступен через выбор комплекта, в том числе во время ожидания возрождения. Для ближней атаки действуют подготовка, активная фаза и восстановление; смена оружия не отменяет восстановление.

Сохраняются внешний вид, настройки, переназначение клавиш, валюта и улучшения. Схема профиля автоматически обновляется до версии 3; ключ `pixel_protocol_profile` сохраняется. Настройка пикселизации удаляется.

## Проверки

```powershell
npm run build:activity
npm run test:unit
npm run test:activity
npm run test:campaign
npm run test:weapons
npm run test:presentation
npm run test:audio
npm test
npm run test:performance
```

Браузерные проверки используют установленный Chrome или Edge; путь можно задать через `CHROME_PATH`. `node tools/activitytest.js --visuals` сохраняет изображения арены и интерфейса. `test:performance` отдельно проверяет настоящий GPU и запускает 15-минутный серверный прогон; программный WebGL не считается доказательством производительности GPU.

Целевые 60–90 минут кампании — ориентир баланса, требующий прохождения человеком. Автоматические проверки подтверждают переходы и условия этапов, но не длительность и сложность живого прохождения.

Архитектура и протокол: [DEVELOPER_GUIDE.md](DEVELOPER_GUIDE.md). Оставшаяся приёмка: [ROADMAP.md](ROADMAP.md).
