# Свой сервер: дуэль с другом через интернет

Игра и сервер комнат работают в Docker на вашем VPS. Перед ними стоит Caddy, он сам получает HTTPS-сертификат Let's Encrypt. Код отправляется с вашего компьютера одной командой `npm run deploy`.

## Что нужно

- VPS с Linux и публичным IP. Для дуэли хватает 1 vCPU и 1 ГБ памяти.
- Домен или поддомен, например `game.example.com`, с A-записью на IP сервера (и AAAA, если у сервера есть IPv6).
- Открытые входящие порты 80/tcp, 443/tcp и 443/udp в файрволе провайдера. Порт 80 нужен для выпуска сертификата.
- Вход на сервер по SSH-ключу: `ssh root@203.0.113.10` должен работать без пароля.
- На своём компьютере: Node.js 22+, git, ssh и tar. В macOS, Linux и Windows 10+ ssh и tar уже есть.

## Первая настройка сервера

Установите Docker вместе с Compose:

```sh
ssh root@203.0.113.10
curl -fsSL https://get.docker.com | sh
```

Если вы подключаетесь не под root, добавьте пользователя в группу docker и зайдите заново: `sudo usermod -aG docker $USER`.

## Деплой

1. Скопируйте `.env.example` в `.env` (если файла ещё нет) и заполните:

   ```ini
   DEPLOY_HOST=root@203.0.113.10
   DEPLOY_DOMAIN=game.example.com
   ```

   В `DEPLOY_HOST` пишется то же, что после `ssh`; подходит и алиас из `~/.ssh/config`. Необязательные настройки:
   - `DEPLOY_PATH`: папка на сервере, по умолчанию `~/pixel-protocol`. Скрипт целиком заменяет её при каждом деплое (кроме `.env`), поэтому указывайте отдельную папку.
   - `DEPLOY_SSH`: команда ssh с флагами, например `ssh -p 2222`.

2. Запустите:

   ```sh
   npm run deploy
   ```

Скрипт отправляет рабочую копию проекта: всё, что не исключено `.gitignore`, включая незакоммиченные правки. Образы собираются на сервере, затем запускается `docker compose up -d`. После этого скрипт ждёт ответа `https://DOMAIN/health` и проверяет дуэль двумя тестовыми клиентами:

```
✓ дуэль 1×1 через https://game.example.com: задержка 41 мс, снимки 20 и 20 в секунду

Готово: https://game.example.com
```

Первый деплой занимает пару минут: сервер скачивает базовые образы, Caddy получает сертификат. Повторный `npm run deploy` обновляет игру.

**Деплой перезапускает сервер, текущие комнаты и матчи сбрасываются.**

## Как сыграть 1×1

1. Откройте `https://game.example.com`, выберите режим **«Дуэль»** и нажмите **СОЗДАТЬ**.
2. Нажмите **ПРИГЛАСИТЬ**. Ссылка вида `https://game.example.com/?room=AB12CD34` скопируется, отправьте её другу.
3. Друг открывает ссылку и сразу попадает в комнату. Можно и вручную: поле «КОД КОМНАТЫ» → **ВОЙТИ**.
4. Оба нажимают **ГОТОВ К БОЮ**, затем создатель нажимает **НАЧАТЬ МАТЧ**.

Позывной меняется в разделе «Боец» до входа в комнату. Нужен компьютер с клавиатурой и мышью или с геймпадом: сенсорное управление не поддерживается. После матча кнопка **В ЛОББИ ДЛЯ РЕВАНША** возвращает обоих в ту же комнату.

Сервер открыт всем, кто знает адрес: вход гостевой, без регистрации.

## Проверка и обслуживание

Проверить работающий сервер можно с любого компьютера с копией проекта:

```sh
npm run check:server -- https://game.example.com
```

Команды на сервере выполняются в папке `~/pixel-protocol`:

| Действие | Команда |
| --- | --- |
| Состояние | `docker compose ps` |
| Логи | `docker compose logs -f --tail=100 game caddy` |
| Перезапуск игры | `docker compose restart game` |
| Остановка | `docker compose down` |

Настройки сервера лежат в `~/pixel-protocol/.env`, деплой обновляет в нём только `DOMAIN`. Здесь же задаются `ROOM_CAPACITY`, `MAX_ROOMS` и ключи Discord из [DISCORD.md](DISCORD.md). После правки выполните `docker compose up -d`.

## Если что-то не работает

- **`npm run deploy` долго ждёт и пишет «не отвечает».** Проверьте, что A-запись указывает на сервер (`nslookup game.example.com`), а порты 80 и 443 открыты в файрволе провайдера. Причину обычно видно в `docker compose logs caddy`.
- **«port is already allocated».** Порты 80/443 занимает другой веб-сервер (nginx, apache). Остановите его или используйте отдельный сервер.
- **«Нет доступа к Docker».** Подключайтесь под root или добавьте пользователя в группу `docker`.
- **«Связь потеряна» в игре после деплоя.** Сервер перезапустился, комнаты сброшены. Через 30 секунд игра вернёт в меню; создайте комнату заново.
- **«Версия игры изменилась».** Обновите страницу.
